# ipad-dev-playbook

How to build and ship real software from an iPad, using only free
browser tools. No laptop and no installs.

## The toolkit
| Tool | What it's for | Cost |
|---|---|---|
| github.com | Create repos, manage files | Free |
| github.dev | Edit code in the browser (press . on any repo) | Free |
| GitHub Codespaces | A full cloud computer with a terminal | Free monthly hours |
| GitHub Pages | Host a website straight from a repo | Free |

## Workflow
1. Create a public repo on github.com with a README.
2. Press . to open github.dev and add your files.
3. Commit: open Source Control, type a message, tap Commit, then Sync Changes.
4. Need to run code? Open a Codespace from the repo (Code > Codespaces).
5. Building a website? Turn on GitHub Pages in Settings > Pages.
6. Done? Stop the Codespace so it stops using free hours.

## Tips for the iPad
- Use a hardware keyboard if you can. Typing code on glass is slow.
- Paste code instead of typing it, and commit often.
- Type a file name with slashes (like skills/demo/SKILL.md) to
  create folders automatically.
- Open a second terminal with the + button if the first is busy.
